# StyleStore - E-commerce de Moda Masculina

E-commerce completo focado em elegância e sofisticação, desenvolvido com HTML, CSS e JavaScript puro.

## 🚀 Tecnologias
- HTML5 Semântico
- CSS3 (Variáveis, Flexbox, Grid)
- JavaScript Vanilla (ES6+)

## 🎨 Design
- **Cores:** Laranja vibrante (#E8440A) sobre fundo Dark (#0A0A0A).
- **Tipografia:** Bebas Neue para títulos e Inter para o corpo.

## 📁 Estrutura de Arquivos
- `index.html`: Estrutura principal.
- `css/style.css`: Estilização e Design System.
- `js/main.js`: Lógica do catálogo e carrinho.
